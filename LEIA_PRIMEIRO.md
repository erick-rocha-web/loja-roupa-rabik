# RUA STUDIO | Pacote independente para Claude Code

Este pacote contém um único SDD e as dez ilustrações para criar uma loja-conceito de streetwear do zero. É uma peça de portfólio da Rabik, não uma loja que vende roupas e não um portfólio pessoal.

## Preparação

1. Crie uma pasta nova, por exemplo rua-studio.
2. Extraia o conteúdo deste pacote nessa pasta. O SDD e assets devem ficar juntos na raiz.
3. Abra somente essa nova pasta no Claude Code. Não use a pasta do projeto anterior.
4. Não é preciso copiar o repositório anterior nem ler os três prompts antigos.
5. Envie a instrução abaixo.

## Instrução para o Claude

Leia integralmente SDD_RUA_STUDIO.md e examine as dez imagens em assets/generated/. Crie do zero a aplicação descrita, nesta pasta nova e independente. Este é um projeto fictício de streetwear para meu portfólio, não um portfólio pessoal. Preserve a intenção da hero cinematográfica especificada, implemente os fluxos de explorar, montar combinação, salvar e exportar, e acrescente as animações secundárias. Não reutilize marca, fotos, contatos, Git ou Vercel do projeto anterior. Não pare no planejamento: entregue o site local funcionando e validado em desktop, mobile e movimento reduzido. Não faça commit, push ou deploy.

## O que tem no pacote

- SDD_RUA_STUDIO.md: especificação única e autossuficiente.
- assets/generated/: dez imagens ilustrativas.
- LEIA_PRIMEIRO.md: estas instruções.

Não contém código pronto, fotos de lojas reais, recortes de fotografias do projeto anterior, credenciais, histórico Git nem configuração de publicação.

## Quando o site estiver pronto

Crie um repositório GitHub vazio e forneça sua URL ao Claude somente quando quiser conectar/publicar. A futura hospedagem deverá usar um projeto novo. O SDD deixa a indexação bloqueada por padrão até uma aprovação separada.

O nome RUA STUDIO é apenas uma marca fictícia de trabalho, editável em src/data/brand.ts. O contato da Rabik é +55 61 98364-5763 e rabik.digital@gmail.com; os botões de contratação devem identificar a finalidade de desenvolvimento de sites.

## Revisão visual dos assets

O arquivo final do personagem azul é assets/generated/look-azul-ilustrado-sem-marca.png. Uma versão anterior tinha um símbolo esportivo reconhecível no tênis; ela não está neste pacote. Foi feita uma edição com o gerador de imagens integrado, preservando personagem, pose, roupas, cores, enquadramento e transparência.

Prompt final da edição: substituir somente os símbolos em forma de swoosh dos dois tênis por painéis e costuras azul/branco sem marca; manter o restante da ilustração e o fundo transparente; não acrescentar texto, logo, objeto ou corte.
